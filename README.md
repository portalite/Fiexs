# Fiexs

Fiexs is an offline-first pixel art generation
Android application.

## Vision

- Offline image generation
- On-device AI
- Pixel art generation
- Live generation visualization
- Export images as PNG
- Custom lightweight AI model

## Planned AI Model

Fiexs-Pixel-1

## Platform

Android

## Technologies

- Kotlin
- Jetpack Compose
- Python
- ONNX Runtime

## Status

Early prototype.
